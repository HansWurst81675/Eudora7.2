# fuer einen Befund zaehlen.

# Gelesen von tools/schranken-gegenprobe.pl (faehrt die Rueckfallprobe) und

# Rueckfallprobe ROT geworden ist - gemessen, nicht vermutet.
#
# Format: Kennung | Schranke | Datei | Rueckfall: alt ==> neu
#   alt muss genau einmal in der Datei vorkommen; \t steht fuer Tabulator.
#   Der Rueckfall nimmt die Behebung zurueck, so knapp wie moeglich.
